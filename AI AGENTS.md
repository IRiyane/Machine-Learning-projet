# Repository workflow

- Start with [README.md](README.md) for the layout and the [project specification](report/project-specification.md) for the assignment.
- Put runnable notebooks in `notebooks/` and submission files in `report/`. Use relative paths and pin notebook dependencies in `requirements.txt`.
- Keep edits focused on the requested task. Run the relevant notebook cells or checks after changing code and report what ran.
- Write submission material in English. Record project discussions, decisions, and open questions in the [discussion log](ai_governance/discussion-log.md) under a dated heading.
- Record team ownership in [CONTRIBUTIONS.md](CONTRIBUTIONS.md), significant prompts in [PROMPT_LOG.md](PROMPT_LOG.md), and verified AI errors and corrections in [AI_AUDIT.md](AI_AUDIT.md).
