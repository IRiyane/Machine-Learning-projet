# Repository workflow

- Start with [README.md](README.md) for the layout and the [project specification](report/project-specification.md) for the assignment.
- Put runnable notebooks in `notebooks/` and submission files in `report/`. Use relative paths and pin notebook dependencies in `requirements.txt`.
- Keep edits focused on the requested task. Run the relevant notebook cells or checks after changing code and report what ran.
- Write submission material in English.

## Required log updates

Before sending your final response, update the applicable project logs yourself. This applies to analysis and review tasks as well as code changes.

- [Prompt log](PROMPT_LOG.md) — Record each substantial project request, such as a notebook review, experiment, or methodology decision. Add the student's exact prompt, the final output you give them, and the checks or constraints used. Record the AI assistant and model used, including the exact variant when known. Use "Not recorded" when the model is unknown. Link to any output delivered as a project file.
- [Discussion log](ai_governance/discussion-log.md) — Record project discussions, decisions, and open questions under a dated heading.
- [Contributions](CONTRIBUTIONS.md) — Record agreed team ownership and supporting evidence.
- [AI audit](AI_AUDIT.md) — Record verified errors in AI outputs, their corrections, and how those corrections were checked.
