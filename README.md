# Machine-Learning-projet

## Repository layout

- `notebooks/` holds the project notebooks. Use relative paths for data and outputs.
- [Project specification](report/project-specification.md) is the working document for the submission. The final report will be exported as `report/Report_Group_XX.pdf` using the team's group number.
- [Discussion log](ai_governance/discussion-log.md) records the team's working discussions.
- [Contributions](CONTRIBUTIONS.md), [prompt log](PROMPT_LOG.md), and [AI audit](AI_AUDIT.md) track the required governance evidence.
- [Requirements](requirements.txt) will list the pinned notebook dependencies after the first baseline run.
